# Интерактивное коммерческое предложение (КП) + генератор под клиента

Одностраничное интерактивное КП для маркетингового агентства с рабочим калькулятором экономики
и формой-брифом, которая собирает персональную страницу под конкретного клиента прямо на созвоне.

## Файлы

| Файл | Назначение |
|------|------------|
| `brief.html` | Форма-бриф: заполняете ответы клиента → «Открыть КП» генерирует персональную страницу |
| `kp.html` | Шаблон КП, который рендерится из данных брифа |
| `index.html` | Исходный (эталонный) вариант КП, пример без персонализации |
| `render.js` | Подставляет данные брифа в шаблон (из ссылки `#data=…` или localStorage) |
| `app.js` | Интерактивный калькулятор экономики (ползунки, 3 сценария) |
| `assets/` | Скомпилированный CSS (Tailwind), шрифты Inter, изображения этапов |

## Как пользоваться

1. Открыть `brief.html`, заполнить поля под клиента (точка А/Б, ниша, город, бюджет, конверсии, чек).
2. Нажать «Открыть КП →» — в новой вкладке откроется персональная страница.
3. Показать её на демонстрации экрана. Кнопка «Скопировать ссылку» формирует ссылку
   вида `kp.html#data=…` со вшитыми данными — её можно отправить клиенту.

## Экономика калькулятора

- Рекламный бюджет — фиксированный ввод (не меняется в калькуляторе).
- Выручка = заявки × конверсия в встречу × конверсия в оплату × средний чек.
- Три сценария (Осторожный / Базовый / Оптимистичный) при одном фиксированном бюджете.

## Локальный запуск

Нужен статический сервер (из-за загрузки шрифтов и картинок):

```bash
python3 -m http.server 8090
```

затем открыть http://localhost:8090/brief.html
